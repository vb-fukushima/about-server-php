# 講師用メモ(非公開想定)

このファイルはVitePressのナビ/サイドバーにリンクしていませんが、リポジトリ自体はpublicなためURLを直接知っていれば誰でも見られます。機密情報は書かないこと。

## 事前準備(講師側)

- PaizaCloudでサーバーを1つ作成し、動作確認済みの状態にしておく
- `public_html`フォルダに以下の2ファイルを用意
  - `index.html`(フォーム)
  - `contact.php`(受け取り処理)
- 当日サーバーがサスペンドしていないか、開始前に一度アクセスして起動しておく
- 無料プランは1つのサーバー環境を作成から24時間で使えなくなるため、当日に近いタイミングで作り直しておく

## セクション4「実際に動かして見せる」の詰まりやすいポイント

- URLに`~ubuntu`を付け忘れて404になる
- ファイル名やフォルダ階層のタイポ(`contact.php`が`public_html`直下にない等)
- 画面が真っ白になる場合は、PHPのエラー表示がオフになっている可能性がある旨を伝え、講師の画面で正解コードを見せて比較してもらう

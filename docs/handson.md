## 構成(30〜40分)

### 1. サーバーとは?(10分)

- 「サーバー」= リクエストを受け取って、レスポンスを返すだけのコンピュータ、というイメージから説明
- 図解イメージ:

```
[ブラウザ] --リクエスト(URLにアクセス、フォーム送信など)--> [サーバー]
[ブラウザ] <--レスポンス(HTML、データなど)-------------------- [サーバー]
```

- 普段Figmaで見ている画面は、実は「レスポンス」として返ってきたHTMLが表示されているという説明
- 「PHPはサーバー上で動いて、このレスポンスの中身を作るプログラム」という位置づけを伝える

#### 振り返り(30秒)

- 声に出さなくてOK、心の中で「サーバーって何?」を自分の言葉で30秒説明してみてください

### 2. フォームからサーバーに送る(5分)

`index.html`:

```html
<form action="contact.php" method="POST">
    <p>お名前: <input type="text" name="name"></p>
    <p>メールアドレス: <input type="email" name="email"></p>
    <button type="submit">送信</button>
</form>
```

- `action`(送り先ファイル)と`method`(送り方: POST)を軽く説明
- `name`属性が、サーバー側で受け取るときの「名札」になる、とだけ触れる

#### 振り返り(30秒)

- `action`と`method`、`name`属性がそれぞれ何をしているか、自分の言葉で30秒説明してみてください

### 3. PHP側で受け取る(10分)

`contact.php`:

```php
<?php
// フォームから送られてきたデータを受け取る
$name = $_POST['name'];
$email = $_POST['email'];

// 本来はここで入力内容をチェックする(バリデーション)処理が入る

// 本来はここでデータベースに保存する処理が入る
// 例: お問い合わせ内容を保存する、会員情報を更新する など

// 受け取った内容をブラウザに返す
echo "<h1>お問い合わせありがとうございます、" . $name . "さん</h1>";
```

伝えたいポイントはこれだけ:

- HTMLの`name="email"`と、PHPの`$_POST['email']`が対応している
- `index.html`(フォーム)と`contact.php`(受け取り)でファイルが分かれていることで、「デザイナーが触る部分」と「サーバー側の処理」の境界がイメージしやすい
- サーバーは「受け取って」「(裏で何かして)」「返す」の3ステップだけ
- `echo`で書いたものがそのままブラウザの画面に表示される、という一番シンプルな対応関係

#### 振り返り(30秒)

- `$_POST['name']`が何をしているか、自分の言葉で30秒説明してみてください

## 使用環境:PaizaCloud

- https://paiza.cloud/
- ブラウザだけでWebサーバー(Apache)+PHPが動く環境が用意できる
- 各MacBookへのPHPインストールやDocker環境構築が不要
- `新規サーバ作成`→用意されたテンプレートから`public_html`配下にファイルを作成し、`ブラウザ`アイコンから動作確認ができる
- アクセスURLの例: `https://<サーバ名>.paiza-user-free.cloud/~ubuntu/index.php`のような形式でアクセスする(サブディレクトリ`~ubuntu`が必要な点に注意)
- 無料プランには利用時間の制限があるため、当日は開始前にサーバーを起動しておく

> [!NOTE] 無料プランの制限について
> - **同時起動数**: サーバーは同時に1台まで
> - **利用期間**: 1つのサーバー環境は作成から24時間で使えなくなる
> - **連続起動時間**: ブラウザを開いている間のみ稼働し、最大4時間(タブを閉じると停止する)
> - **スペック**: CPU 2コア / メモリ2GB / ディスク1GB
> - **外部公開**: 独自ドメインでの一般公開は不可。ただし`https://<サーバ名>.paiza-user-free.cloud/...`のようなURLへの一時的なアクセスは可能(このハンズオンで使う分には問題なし)
>
> **参加者への案内**: ハンズオン中はPaizaCloudのタブを閉じない(閉じるとサーバーが停止する)。万一サーバーが使えなくなった場合は、新規サーバーを作成し直せばリカバリできる

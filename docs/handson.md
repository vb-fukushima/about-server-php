## 1. サーバーとは?(10分)

例えば、URLにhttps://google.com と書いてエンターを押すとどうなるでしょうか。

自分のパソコンから通信されて、世界のどこかにあるgoogleサイトのファイルが置いてあるパソコンに、
htmlとかcssとか頂戴！と依頼します。<br>
するとそのパソコンは いいよ！ と言いつつ、表示するhtml/css/JS等自分のパソコンに返してくれます。


この情報を返してくれるパソコンを「サーバー」といいます。<br>
一方、自分の方のパソコンは「クライアント」といいます。

クライアントからサーバーへ情報をちょうだい！と依頼することをリクエストを送るといいます。<br>
一方、サーバーからクライアントへ情報を返すことをレスポンスといいます。

つまり、サーバーは受け取って返すだけのシンプルな存在です。

![リクエストとレスポンスの図解](/diagrams/request-response.svg)

> [!TIP] 🔔サーバーは特別なパソコンじゃない
> 「サーバー」と聞くと、なにか特別な機械を想像するかもしれませんが、実はそうではありません。
>
> サーバーの正体は、「リクエストを受け取ったらレスポンスを返す」というソフト(Webサーバーソフト)が入っているだけの、ただのパソコンです。<br>
> 代表的なWebサーバーソフトには`Apache`や`nginx`があります。
>
> なので、理論上は自分のMacBookも「サーバー」にできます。

ここでもう一つ、Webサイトには「静的サイト」と「動的サイト」という分け方があります。

- **静的サイト**: あらかじめ用意されたHTMLファイルを、そのままレスポンスとして返すサイト。誰がアクセスしても同じ内容が返ります。
- **動的サイト**: アクセスしてきたユーザーや入力内容によって、レスポンスの内容を変えるサイト。「ログインしている人には名前を表示する」「フォームの入力内容に応じて表示を変える」といったことができます。

<!-- ![静的サイトと動的サイトの違い](/diagrams/static-vs-dynamic.svg) -->

この動的なコンテンツをユーザーごとに組み立てて返すために使われるプログラムの一つが、PHPです。<br>
サーバー上でPHPが動くことで、アクセスしてきた人や送られてきたデータに応じて、レスポンス(HTML)の内容を変えることができます。

> [!TIP] 🔔PHPはTEXTとして送られる
> 実はPHPファイルはサーバー側で処理されると、最終的に、TEXTとなってブラウザにレスポンスされます。
> (さらに実は、HTMLもテキストとしてブラウザに渡されます。)
> PHPファイルにHTMLタグを(ちゃんとした方法で)書くと、それがブラウザに戻るときにはTEXTとして渡されます。
> ブラウザは、TEXTの中にHTMLタグがあるとそれを処理して描画します。
> つまりPHPにはHTMLタグもかけるよ、ということです。詳細はハンズオンで確認しましょう。

これから実際にやることを、リクエスト/レスポンスの流れで見てみましょう。

![ハンズオンの流れ(ページを開く→フォーム送信)](/diagrams/handson-flow.svg)

では、実際にPaizaCloud上で作ってみましょう。

1. PaizaCloudにログインし、新規サーバーを作成する(これは事前準備ができていればok)
2. サーバー起動後、`public_html`フォルダに`index.html`を新規作成し、↓のコードをコピペ・保存する。

![PaizaCloud 新規ファイル作成](/paizacloud/paiza_0006.png)

`index.html`:

```html
<form action="contact.php" method="POST">
    <p>お名前: <input type="text" name="name"></p>
    <p>メールアドレス: <input type="email" name="email"></p>
    <button type="submit">送信</button>
</form>
```

`action`は送り先のファイル、`method`は送り方(ここでは`POST`)を指定しています。

`name`属性は、サーバー側で受け取るときの「名札」になります。

> [!TIP] 🔔methodについて
> ここでは、POSTというものを書いていますが、もう一つGETというものがあります。
> GETとPOSTは明確に異なり、用法も異なります。
> 一旦ここでは説明を省きますので、気になる方はAIか福島さんに聞いてください。


> [!TIP] 🔔actionについて
> ここに書いた先に、リクエストを送ることができます。
> 今回の場合は、同じサーバー内に送りたいので、このような書き方になっています。
> 例えば、受け取る準備ができていれば、https://HOGEFUGA.jp といった任意の場所に送ることが可能です。


## 3. PHP側で受け取る(10分)

では次に、`contact.php`も作成しましょう。
このファイルでは、リクエストされて受け取った内容をphpで動的に変化させてレスポンスします。

1. `public_html`フォルダに`contact.php`を新規作成する
2. 下記のコードをコピペする


```php
<?php
// フォームから送られてきたデータを受け取る
$name = $_POST['name'];
$email = $_POST['email'];

// 本来はここで入力内容をチェックする(バリデーション)処理が入る

// 本来はここでデータベースに保存する処理が入る
// 例: お問い合わせ内容を保存する、会員情報を更新する など

// 受け取った内容をブラウザに返す
echo "<h1>お問い合わせありがとうございます、" . $name . "さん</h1>";
```

ここで持ち帰ってほしいポイントは、この3つです。

- HTMLの`name="email"`と、PHPの`$_POST['email']`が対応しています
- サーバーは「受け取って」「(裏で何かして)」「返す」の3ステップだけです
- `echo`で書いたものが、そのままブラウザの画面に表示されます(一番シンプルな対応関係です)

## 使用環境:PaizaCloud

- https://paiza.cloud/
- ブラウザだけでWebサーバー(Apache)+PHPが動く環境が用意できる
- 各MacBookへのPHPインストールやDocker環境構築が不要
- `新規サーバ作成`→用意されたテンプレートから`public_html`配下にファイルを作成し、`ブラウザ`アイコンから動作確認ができる
- アクセスURLの例: `https://<サーバ名>.paiza-user-free.cloud/~ubuntu/index.php`のような形式でアクセスする(サブディレクトリ`~ubuntu`が必要な点に注意)
- 無料プランには利用時間の制限があるため、当日は開始前にサーバーを起動しておく

> [!NOTE] 無料プランの制限について
> - **同時起動数**: サーバーは同時に1台まで
> - **利用期間**: 1つのサーバー環境は作成から24時間で使えなくなる
> - **連続起動時間**: ブラウザを開いている間のみ稼働し、最大4時間(タブを閉じると停止する)
> - **スペック**: CPU 2コア / メモリ2GB / ディスク1GB
> - **外部公開**: 独自ドメインでの一般公開は不可。ただし`https://<サーバ名>.paiza-user-free.cloud/...`のようなURLへの一時的なアクセスは可能(このハンズオンで使う分には問題なし)
>
